# Event Platform 🎟️

Современная платформа для поиска и организации мероприятий, построенная на Next.js 15 с полной интеграцией реального бэкенд API.

## 🚀 Особенности

- **Полная аутентификация** с JWT токенами
- **CRUD для мероприятий** с реальным API
- **Регистрация на мероприятия** и управление участием
- **Адаптивный дизайн** на TailwindCSS
- **Управление состоянием** через Redux Toolkit + RTK Query
- **Защищенные маршруты** и ролевой доступ
- **Редактирование профиля** пользователя

## 🛠️ Технологии

- **Frontend:** Next.js 15, TypeScript, React 18
- **Стили:** TailwindCSS v4
- **State Management:** Redux Toolkit, RTK Query
- **Роутинг:** Next.js App Router
- **API Integration:** REST API с JWT аутентификацией
- **UI Components:** Кастомные компоненты на TailwindCSS
